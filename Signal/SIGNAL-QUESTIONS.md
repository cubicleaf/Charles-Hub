# Signal — Scoping Questions

*Working name; rename freely. **Project:** a manually-run routine that researches how commodity economics (prices, supply disruptions, extraction/policy deals) move specific company stock prices. First domain: rare earth elements (REE).*

---

## How to use this
Answer top to bottom. Each stage **gates** the next — resist jumping to data sources before purpose is fixed. One line per answer is enough.

---

## Stage 1 — Purpose & Output  *(answer before anything else)*
1. **What does this feed?**  Personal investing / content product / AI-consulting demo / learning the domain.
2. **Time horizon of the moves you care about?**  Intraday–days / weeks–months / multi-year thesis.
3. **What's the deliverable?**  Daily brief / threshold alerts / a living thesis doc per company.

> Why this is first: if (2) is "multi-year thesis," latency and real-time price data stop mattering and the whole build gets simpler and cheaper.

## Stage 2 — Scope
4. **Which part of the value chain?**  Upstream miners / separators & processors / magnet makers / downstream consumers (EV, defense, wind).
5. **Which REEs?**  Magnet group only (Nd, Pr, Dy, Tb) / full basket / not sure yet.
6. **Whose policy matters?**  US (DoD / DOE / USGS) / China export controls / EU / allied supply deals / all.
7. **Starting universe — name 3–8 companies.**  Track a few well rather than fifty badly.

## Stage 3 — Data & Feasibility  *(the hard part for REE)*
8. **Price data — pay or proxy?**  Pay (Argus / Fastmarkets / Asian Metal) / proxy via USGS + Lynas realized prices + REMX index / skip price for now.
9. **News & policy sources — primary or press?**  Primary only (SEC/SEDAR filings, exchange announcements, .gov releases, RSS) / include trade press / unsure. *(Scraping paywalled trade press has terms-of-service problems — flag if that's the plan.)*
10. **Cadence?**  Once daily / event-driven / weekly digest.

## Stage 4 — Validation
11. **Backtest first or go qualitative?**  Check whether these events historically moved these stocks / start qualitative and refine.
12. **What does "working" look like?**  Time saved / a move it flagged early / a sharper written thesis.
